# Demonstration artwork

The demo catalog uses repository-native flat SVG illustrations in public/demo (sari, panjabi, three-piece, kurti, lungi, shirt, hijab, kids frock, shawl and two hero banners). They were generated for this project and need no licence. They are illustrations, not product photographs: they do not show the real material, cut or colour of any item. Replace them with your own product photography (JPEG, PNG or WebP) through the Media screen before launch.

Seeding copies each SVG to the public media disk and creates a media record. The admin upload form accepts JPEG, PNG and WebP only. tests/Fixtures/upload.jpg is a generated placeholder image used by browser tests.

The vector placeholder in public/images/placeholder.svg is repository-native artwork. No image generation service was used.
